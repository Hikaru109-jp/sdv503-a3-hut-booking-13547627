# sdv503-a3-hut-booking-13547627
This repository is for Assessment 3.

[What this app is about]
This app is for managing huts and reservations which improves the accuracy and efficiency of hut booking.
In this app, you can register huts, record bookings, show a specific booking list you choose, show a booking summary, cancel bookings, and save the data.


[How to run this code]
To run this code, you have to enter "node index.js" first. After that, the app will start and go to the main menu. In the main menu, you can choose one command from each of them. One thing you have to do first after starting the app is register at least one hut. Otherwise, all commands except "RegisterHut" and "Exit" won't work.
